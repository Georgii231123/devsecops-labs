# Golden Path Principles

1. **Self-service:** a developer can create a compliant service without waiting for the platform team.
2. **Opinionated defaults:** health probes, resource limits, non-root execution and CI checks exist from day one.
3. **Escape hatches are explicit:** teams can diverge, but exceptions should be reviewed rather than silently deleting controls.
4. **Everything as code:** templates, dashboards, policies and documentation are versioned together.
5. **Fast feedback:** platform validation runs before deployment so engineers see actionable errors in pull requests.

The goal is not to own application code. The platform owns the paved road and reduces repeated operational work across teams.
